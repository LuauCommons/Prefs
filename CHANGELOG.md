# Changelog

## [0.1.0] - Beta

- Initial release of the framework-independent Prefs preferences layer.
- Added boolean, number, string, and enum schemas with defaults and validation.
- Added attached-table reconciliation, serialization/loading, observers, reset operations, and cleanup.
- Added server-authoritative client synchronization with generated remotes, permissions, revisions, and rate limiting.
- Added Rojo and Wally release artifacts and Studio integration fixtures.
